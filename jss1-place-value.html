🧠 2. LET'S BEGIN FROM SCRATCH

Look at these two numbers:

5    and    50

They both contain the digit 5.

But are they worth the same?

No.

In 5, the 5 means:

5 ones

In 50, the 5 means:

5 tens = 50

Now look at:

500

The 5 means:

5 hundreds = 500

So we can see something very important:

The position of a digit determines its value.

This is called PLACE VALUE.

📖 3. WHAT IS PLACE VALUE?

Definition

Place value is the value of a digit because of the position it occupies in a number.

Let's make it simpler:

Place tells us where the digit is.
Value tells us what the digit is worth there.

5

The 5 is in the ones place.

Its place value is:

5

50

The 5 is in the tens place.

Its place value is:

50

500

The 5 is in the hundreds place.

Its place value is:

500

Same digit → Different position → Different value.

🔢 4. THE BASIC PLACE VALUES

Let's begin with the smallest places.

Place Value
Ones 1
Tens 10
Hundreds 100
Thousands 1,000
Ten Thousands 10,000
Hundred Thousands 100,000
Millions 1,000,000
Notice the pattern:

1 → 10 → 100 → 1,000 → 10,000 → 100,000 → 1,000,000

Every time we move one place to the left, the value becomes 10 times greater.

🧠 13. FACE VALUE VS PLACE VALUE

This is extremely important.

There are two different ideas:

FACE VALUE

The face value of a digit is simply the digit itself.

PLACE VALUE

The place value depends on where the digit is located.

Example

Consider:

4,682

Look at the digit 6.

Face value = 6

Place value = 600

Why?

Because 6 is in the hundreds place.

Face value = the digit itself.

Place value = the digit's value according to its position.

💡 15. THE ZERO PROBLEM

Zero can occupy a place even though its value is zero.

5,042
Thousands Hundreds Tens Ones
5 0 4 2

Here:

5 = 5,000
0 = 0 hundreds
4 = 40
2 = 2
5,042 = 5,000 + 40 + 2
The zero is important because it holds the hundreds place.

Without it, 5,042 would become 542, which is a different number.
